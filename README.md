# mortb.online — مُرتَّب

موقع عربي يقدّم أكثر من 43 أداة وحاسبة مجانية تعمل داخل المتصفح، موجّهة لمستخدمي
المملكة العربية السعودية.

## البنية

- صفحات ثابتة (HTML/CSS/JS) بلا أي خطوة بناء على الخادم — تُرفع كما هي.
- التواريخ الهجرية محسوبة بجداول **تقويم أم القرى** الرسمية (1370هـ–1500هـ)،
  وتم التحقق من كل حدود الأشهر في هذا النطاق.
- مواقيت الصلاة محسوبة فلكياً بمعايير جامعة أم القرى (فجر 18.5°، عشاء +90 دقيقة).
- كل الحسابات تجري في متصفح الزائر — لا خادم ولا قاعدة بيانات ولا جمع بيانات.

## الملفات

```
index.html            الصفحة الرئيسية
tools/                43 أداة
category/             6 صفحات تصنيفات
blog/                 10 مقالات + الفهرس
assets/               CSS و JS
_gen/                 مولّدات بايثون (لا تُنشر — لبناء الصفحات فقط)
sitemap.xml, robots.txt, vercel.json
```

## إعادة البناء

pip install hijridate
